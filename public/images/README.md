# Как заменить изображение

1. Подготовь свою фотографию (JPG или PNG)
2. Назови файл `love-photo.jpg` (или измени имя в `src/App.tsx` строка с `src="./images/..."`)
3. Положи файл в эту папку `public/images/`
4. Запуш изменения в GitHub
5. Готово! Изображение обновится автоматически

## Рекомендуемые размеры
- Ширина: 800-1200px
- Высота: 600-900px
- Формат: JPG или PNG
- Размер файла: до 2MB
